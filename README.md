# WhatsApp Agent Platform

A Node.js-based platform for building WhatsApp automation agents with clean architecture and modular design.

## Features
- WhatsApp Web API integration
- Message handling middleware
- User session management
- Automated response systems
- Webhook support

## Setup
1. Install dependencies: `npm install`
2. Configure environment variables in `.env`
3. Start development server: `npm run dev`

## Dependencies
- Node.js (v18+)
- Express.js
- WhatsApp Web API client
- dotenv
