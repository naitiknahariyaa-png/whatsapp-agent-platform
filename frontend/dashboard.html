📦 SDKs

Node.js, Python, PHP client libraries

📦 Node.js SDK
npm install @wa-platform/sdk const { Client } = require('@wa-platform/sdk'); const client = new Client({ apiKey: 'YOUR_API_KEY' }); await client.sendMessage({ to: '+919876543210', text: 'Hello!' });
🐍 Python SDK
pip install wa-platform-sdk from wa_platform import Client client = Client(api_key="YOUR_API_KEY") client.send_message(to="+919876543210", text="Hello!")
🐘 PHP SDK
composer require wa-platform/sdk $client = new WaPlatform\Client("YOUR_API_KEY"); $client->sendMessage("+919876543210", "Hello!");
